# OpenClaw Diagnosis

面向服务器日志分析的本地 AI 诊断系统，让故障排查有据可查。

> 本仓库用于公开展示项目与收集反馈。应用源码保存在私有仓库中，不在此仓库提供。

## 项目简介

OpenClaw Diagnosis 将日志上传、证据检索、AI 分析和结果展示串联起来，帮助排查服务器问题。诊断结果包含证据引用、分析范围和后续建议，便于人工复核。

## 核心功能

- **日志接入**：上传日志包，整理来源并建立可检索的日志索引。
- **AI 辅助诊断**：根据问题检索日志、读取上下文并分析时间线。
- **证据可追溯**：诊断结论关联日志证据，便于回看与核对。
- **结构化结果**：区分发现故障、未发现故障与证据不足，并给出后续建议。
- **任务与版本管理**：查看分析进度，支持重新分析和结果版本追踪。
- **Web 工作台**：提供日志上传、任务查看、结果浏览及权限管理。
- **本地部署**：支持本地模型推理，适用于本地日志分析场景。

## 使用流程

上传日志包 → 创建分析任务 → AI 检索证据与分析 → 查看诊断结果 → 人工复核与后续排查。

AI 诊断用于辅助排查；结论受日志覆盖范围和证据完整性影响，需要结合实际环境复核。
